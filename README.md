# ArbMusic 🎵

Твой музыкальный плеер с тёмным дизайном — для Android (APK), iPhone (IPA/PWA) и Windows (EXE).

## ☁️ Облачная версия (PWA) — работает на всём, без установки

**https://arbmusic-7371.zai-ai.site**

- Треки хранятся в базе (IndexedDB) на устройстве, приложение кэшируется service worker'ом
- Работает **полностью без интернета** после первого импорта музыки
- На iPhone: Safari → Поделиться → «На экран “Домой”» — без кабеля и подписи
- Деплой: `tools/` + `.zcode-site/stage` (ZCode Sites, статика)

## Что внутри

- **Микс** — все твои треки в случайном порядке одной кнопкой
- **Моя музыка** — сохранённые (избранные) треки, сердечко у каждого трека
- **Поиск** — по названию и исполнителю
- **Плеер**: перемотка, след./пред. трек, перемешивание, повтор (очередь/трек), обложка из тегов
- **Текст песни** — кнопка «Текст песни» в плеере. Синхронный текст из `.lrc`-файла: строки подсвечиваются и листаются сами, тап по строке — перемотка

## Android — установка

Готовый APK: `android/app/build/outputs/apk/debug/app-debug.apk`

1. Скинь APK на телефон
2. Открой его, разреши установку из неизвестных источников
3. При первом запуске приложение попросит **доступ ко всем файлам** — разреши и вернись
4. Жми «Обновить» — ArbMusic найдёт всю музыку на устройстве

## iPhone — установка (IPA)

Без компьютера с macOS/подписи разработчика собранный **без подписи (unsigned) IPA** делают так:

### Способ 1 — GitHub Actions (бесплатно, без Mac)

1. Создай репозиторий на GitHub и загрузи туда эту папку (без `node_modules`)
2. Вкладка **Actions** → workflow **Build iOS IPA** → **Run workflow**
3. Через ~5 минут скачай артефакт `ArbMusic-unsigned-ipa` — внутри `ArbMusic-unsigned.ipa`

### Способ 2 — подпись и установка на iPhone

1. Скачай [Sideloadly](https://sideloadly.io) (Windows)
2. Подключи iPhone кабелем
3. Перетащи `ArbMusic-unsigned.ipa` в Sideloadly
4. Введи свой Apple ID → **Start**
5. На iPhone: Настройки → Основные → VPN и управление устройством → доверь своему Apple ID
6. Готово (бесплатный Apple ID надо переподписывать раз в 7 дней)

### Как закинуть музыку на iPhone

Файлы приложения → Finder (или приложение «Файлы») → **ArbMusic** → скопируй туда mp3/flac и `.lrc` файлы (текст с тем же именем, что и трек).

## Текст песни (.lrc)

Положи рядом с треком файл с тем же именем:

```
Song.mp3
Song.lrc
```

Формат `.lrc`:
```
[00:12.50]Первая строка текста
[00:17.30]Вторая строка
```

## Сборка Android из исходников

```bash
npm install
npx cap sync android
cd android && ./gradlew assembleDebug
```

## iOS-сборка из исходников

Локально на Mac:
```bash
npm install
npx cap sync ios        # запустит pod install
open ios/App/App.xcworkspace   # сборка/запуск в Xcode
```
Через CI: `.github/workflows/ios.yml` собирает unsigned IPA автоматически.

## Структура проекта

```
www/                    интерфейс (HTML/CSS/JS)
android/                Android-проект + нативный сканер (Java)
ios/                    iOS-проект (Xcode)
plugins/arbmusic-scanner/  нативный iOS-сканер (Swift, локальный Capacitor-плагин)
tools/gen-icon.js       генератор иконки приложения
.github/workflows/      CI для сборки IPA
```
